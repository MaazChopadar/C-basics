## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/MAfshaan17/C-basics.git
```

### 2. Navigate to the project

```bash
cd C-basics
```

### 3. Compile a C program

Make sure you have GCC installed.

```bash
gcc pointers.c -o pointers
```

### 4. Run the program

**Windows:**
```powershell
.\pointers.exe
```

**Linux / macOS:**
```bash
./pointers
```

Replace `pointers.c` with the filename of whichever program you want to run.

## 🛠️ Requirements

- A C compiler such as GCC
- A code editor such as Visual Studio Code
- A terminal or command prompt
- Curiosity, consistency, and a willingness to learn!

Check whether GCC is installed:

```bash
gcc --version
```
